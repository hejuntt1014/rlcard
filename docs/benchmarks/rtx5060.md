# RTX 5060 A3 training measurement

Measured on 2026-10-06 using commit
`9cfbcd7944e2301549bddddcd2aa2e86df982d92`.
The [raw measurements](rtx5060.json) include all six runs.

## Hardware and configuration

- Intel Core i5-14400F, 16 logical CPUs, approximately 32 GB RAM.
- NVIDIA GeForce RTX 5060, 8,151 MiB memory, driver 610.57.04.
- Linux, Python 3.13.5, PyTorch 2.13.0+cu130, CUDA 13.0.
- A3 C++ backend, shared ResNet `[512, 512, 512, 512, 512]`, auxiliary heads.
- One actor process; actor CPU inference uses one Torch thread.
- Learner on GPU 0, FP32, batch size 32, unroll length 20, 64 buffer slots.
- 256,000 trained samples (400 optimizer updates) per run, seeds 42 and 43.
- Pure self-play without rule-opponent mixing; weight publication every 50 updates.

## Results

| Actor inference | Environments per actor | Mean end-to-end samples/s | Sampled peak whole-device memory |
| --- | ---: | ---: | ---: |
| CPU | 32 | 5,227 | 1,009 MiB |
| GPU | 32 | 23,391 | 1,220 MiB |
| GPU | 128 | 30,713 | 1,222 MiB |

Throughput uses the arithmetic mean of two per-run rates. Elapsed time includes
Python imports, model and process startup, training, shutdown, and the final
checkpoint. It is not the trainer's shorter-window FPS value.

Whole-device memory was sampled every 0.5 seconds with `nvidia-smi` and includes
approximately 714 MiB of pre-existing background allocation. These sampled peaks
are not exact allocator high-water marks. All six jobs completed, and none emitted
the CUDA IPC shutdown warning checked by the runner.

GPU inference improved throughput for this model and single-actor setup. CPU
actors used less GPU memory. The measurements do not establish optimal settings
for this card, speedups over upstream RLCard, or time to a given policy quality.
Transformer models and other games require their own measurements.

## Reproduce

Install the project with Torch, build the native backend, and use a Linux CUDA
environment with GPU 0 available:

```bash
python docs/benchmarks/run_rtx5060.py 256000
```

The runner saves checkpoints, logs and a JSON report under
`experiments/rtx5060-profiles-256000/`. It does not stop other services. Use the same
configuration and avoid competing GPU work when comparing results.
